The one idea

Every other coupon site competes on how many codes it holds. Clover competes on knowing which ones still work. That is the whole design. Codes are visible without clicking anything, they carry a count of who they actually worked for, and dead ones take themselves off the list.

There is no account. Nothing is uploaded except the votes and codes you choose to share. You can read the entire thing, because the site is one file.

The pieces

  • The shop at the top, with a small mark drawn from its name. Tap it to see every code for that shop.
  • The code itself in the dark pill. Tap to copy. It turns yellow for a moment so you know it took.
  • What it does, in plain words. Dollars off, percent off, free shipping.
  • The catch, underneath in the amber box. Minimum spend, members only, one shop only, app only. If a code has a restriction, it is written down rather than left for you to discover at checkout.
  • The tags: the region (Anywhere, EU wide, United States) and the kind of shop.
  • The ring on the left, showing how often it has worked, and the two buttons on the right to say what happened for you.

After you copy a code, Clover asks whether it worked. Answering takes one tap and it is the entire reason the list is any good.

Trust

The three lines, and what they really mean

a person tested this, worked 12 days ago

Somebody put this code in a real cart and watched the total drop. This is the only line that means a human checked, and it says when. It is a small number of codes and it grows one cart at a time.

Clover's checker ran this 3 days ago

Clover's own checker put the code through a cart automatically. Worth something, but a machine can miss what a person would catch, so it sits below a real person and above nothing, and it never turns green. Other coupon sites badge codes their own software checked, and Clover does not repeat those, because someone else's badge is their marketing rather than evidence.

nobody has tried it yet

Copied from a public listing because it was posted or used recently. No claim at all is being made about it. Try it and tell everyone what happened.

The ring

How the number is worked out

The ring shows the share of people a code worked for. But under three reports it shows a word instead of a number, because two people is not a percentage.

  • high, mixed, low — fewer than three reports
  • 67% — three or more reports, so the number means something
  • 1x — a one-use code, kept out of scoring entirely
  • — — nobody has reported yet

You will never see 100% or 0% off a single vote. The same rule holds for the big "Working" number at the top of the site: it only becomes a percentage once five codes each have three or more reports, and says "early" until then. A code that falls below 40% with at least four votes retires itself and disappears from the list, though you can still see it by ticking show retired and expired. It stays visible on purpose: knowing somebody tried it and it failed is worth more than the code quietly vanishing.

Voting

Saying whether it worked

WorkedNope

One vote per code per device. Tapping the same button again takes your vote back. Tapping the other one moves it. There is no account, so this is honour-system with a small lock on it, and that is a deliberate trade for not asking you to sign up. Your first vote on a code also goes to the shared list, so everyone sees the tally move.

Check the total, not the box. Some shops accept a code and take nothing off, or apply it to one item only. That is still a no.

Finding things

Search and filters

Search matches the shop, the code and the description. Below it are three rows of filter chips: store, kind and region.

All 224 fanatics.com 19 elegoo.com 9 nespresso.com 0

Every chip carries a live count showing what you would get with your other filters already applied. A chip that would leave you with nothing goes faint and stops responding, so you cannot walk into an empty page by accident. If you land on one anyway, the message names which filters caused it and gives you one button to clear them all.

The store row shows the seven busiest with a more chip for the rest.

Order

Why codes are in the order they are

  1. Worked for people, best rate first, then biggest discount, then most recently confirmed.
  2. Untested, with anything Clover's checker ran first, then biggest discount, because that is the only signal there is before anyone has tried.
  3. Failed, least bad first, at the bottom.

So the thing most worth trying is always at the top, and the list quietly improves as people report back.

Adding

Putting a code in yourself

  1. Open Add a code that worked.
  2. Store and code are the only things required.
  3. Write the catch in the restrictions box if there is one. This is the most useful field on the form.
  4. Runs out on, if you know is optional. Leave it blank rather than guessing, a made-up date is worse than none.
  5. Your name is optional. Put one in and it shows on the card as "added by".

The code goes into the shared list straight away, and the page jumps to that store so you can see it. You can edit or delete anything you added. Editing keeps the votes. Deleting asks twice.

Delete a code only if it never existed, like a typo. If it existed and simply stopped working, vote it down instead. A retired code stops the next person adding it back.

Creators

Deals and referral links

Creator deals are codes and links that belong to somebody who made something, and using them sends the credit to them. They live under "Behind a link" in the Why section. Clover never swaps one in for you and takes nothing from it.

Referral links sit in the same place. Anyone can add one, but only if they say what the person clicking gets. A link with nothing in it for you is just commission farming and the form refuses to save it. When several people have a link for the same shop, Clover picks one at random each visit rather than always showing whoever got there first. These stay in your own browser.

Limited codes wear a purple limited badge. These are one-use or first-order codes. They are excluded from every score, because a one-use code failing for the next person is expected rather than evidence of anything.

The extension

Clover at the checkout

Chrome, Edge, Brave, Opera. Download the zip from the button on the main page, unzip it, open chrome://extensions, turn on developer mode, and choose Load unpacked.

Firefox on a computer. Swap manifest-firefox.json in as manifest.json first, then load it the same way from about:debugging.

Firefox on Android. This does work, with some setting up. Use manifest-android.json as manifest.json, because Mozilla still recommends the older extension format for phones. Then the extension has to be signed by Mozilla and put in a collection, since Android Firefox cannot install from a file the way a computer can:

  1. Make a Firefox account and go to the add-ons site.
  2. Submit the extension there to get it signed. Choose the unlisted option if it is only for you.
  3. Make a collection, add Clover to it, and note the collection name and the user id number in the address bar.
  4. On the phone, open Firefox settings, go to About Firefox, and tap the logo five times to turn on the debug menu.
  5. Back in settings, under Advanced, tap Custom Add-on collection and put in that user id and collection name. Firefox will restart.
  6. Open Add-ons and Clover will be there to install.

What it does at a checkout

  1. Finds the promo code box on the page, opening the "add a discount" section if the shop hides it.
  2. Types in each code it knows for that shop, one at a time, and watches the order total.
  3. Tries every code, then applies the winners together where the shop lets codes stack.
  4. Tells you what it saved, and asks whether it worked so the tally stays honest.

The clover in the corner

It has four faces. Idle while waiting, looking while it works, happy when something lands, and sad when nothing does. A little bubble underneath says exactly which code it is trying, so you can watch it work rather than trust it.

It stays quiet if somebody sent you

If the address of the page carries a referral tag, the extension does nothing at all. Somebody already earned the credit for that visit and it is not Clover's to take. This is the single most important line of code in the whole project.

Settings

Right click the extension and choose options, or tap Settings at the bottom of the popup. Everything saves as you change it, there is no save button. You can turn the whole thing off, hide the clover, move it to another corner, make it try codes without asking, change how long it waits between codes, block it from certain shops or allow it on only a few, switch the theme, turn off the mascot or the confetti, and hide creator deals.

The rest of the page

The other sections

  • Stores — every shop with its live code count and best current code. Tap one to see its codes.
  • The wanted board, under the stores — ask for a shop nobody has covered. When somebody adds a code for it, the row turns green and links straight to it. The board lives in your browser.
  • Why — where the codes come from, the Honey story, what was found, how Clover compares (including the rows it loses), and creator deals and referral links.
  • Always on — student schemes and standing offers that need no code hunting.
  • Get the extension — the download, the install steps, and the sync file that carries this page's working codes into the extension.

Privacy

What Clover never does

  • No account, ever.
  • No analytics, no tracking. The only thing that leaves your browser is a vote or a code you chose to share, and that is sent without a name.
  • Nothing else is fetched from anywhere while you read the page. The fonts ship with the site. Even the little shop marks are drawn on your machine from the shop name, because asking an icon service for them would tell that service every shop you looked at.
  • The extension reads the checkout page you are already on, looks at the promo box and the total, and stops there. Not your cart, not your details, not where else you have been.
  • It never adds a referral link, and never replaces one.
  • No cashback. Earning cashback means attaching a tracking tag to your purchase, which is the exact thing Clover was built to be the opposite of.

Everything above can be checked. The site is one file and the extension is a handful of small ones, all readable.

Honestly

What Clover is not good at

No automatic daily rechecking yet, so codes go stale until a person reports. No price history, so it cannot tell you whether a sale is real. The extension fills codes properly on a few shops and guesses on the rest. No phone extension without the setup above. A few dozen shops against competitors with hundreds of thousands. And one person runs it.

All of that is written into the comparison table on the main page on purpose. A chart where one side wins everything is not worth reading.
